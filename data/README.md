# Dataset: CIC-IDS2017

## Overview

The **CIC-IDS2017** dataset was published by the Canadian Institute for Cybersecurity (CIC) at the University of New Brunswick. It contains labeled network flow records for 5 days of traffic, covering 15 traffic classes (BENIGN + 14 attack types).

**Reference:** Sharafaldin, I., Habibi Lashkari, A., & Ghorbani, A. A. (2018). Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization. *Proceedings of the 4th International Conference on Information Systems Security and Privacy (ICISSP)*, 108–116.

---

## Manual Download Instructions

This dataset cannot be downloaded automatically. You must download it manually from the official source.

### Step 1: Go to the official download page

**URL:** https://www.unb.ca/cic/datasets/ids-2017.html

### Step 2: Download the MachineLearningCSV package

Look for the download link labeled **"MachineLearningCSV.zip"** (or similar). This contains pre-extracted flow features as CSV files — you do NOT need to process raw PCAP files.

- Direct download page: https://www.unb.ca/cic/datasets/ids-2017.html
- If prompted for registration, complete it — the dataset is free for research use.

### Step 3: Extract and place files

After downloading and extracting `MachineLearningCSV.zip`, place **all CSV files** into:

```
data/raw/
```

### Expected files

The archive should contain the following CSV files (one per day of capture):

| File | Day | Approx. Size |
|------|-----|--------------|
| `Monday-WorkingHours.pcap_ISCX.csv` | Monday (BENIGN only) | ~110 MB |
| `Tuesday-WorkingHours.pcap_ISCX.csv` | Tuesday (FTP-Patator, SSH-Patator) | ~90 MB |
| `Wednesday-workingHours.pcap_ISCX.csv` | Wednesday (DoS attacks, Heartbleed) | ~70 MB |

## Important Notes

- **Do not rename the CSV files.** The pipeline uses glob matching on `.csv` extension.
- **The Label column has a leading space** in the original files: `" Label"` not `"Label"`. The `data_loader.py` strips this automatically.
- **Some columns contain infinite values** (e.g., `Flow Bytes/s` for zero-duration flows). These are handled in `preprocessing.py`.
- **Monday's file contains only BENIGN traffic** — it contributes to the majority class.
- **Heartbleed has very few samples** (~11 rows). This class may be excluded from stratified splitting.

---

## Known Dataset Limitations

1. **Age:** The dataset was captured in 2017. Attack patterns, protocols, and traffic distributions have evolved significantly since then.
2. **Lab environment:** Traffic was generated in a controlled network, not a real enterprise environment. Feature distributions may not match production traffic.
3. **CICFlowMeter artifacts:** Some features contain `inf` or `NaN` values due to edge cases in the flow meter software.
4. **Class imbalance:** BENIGN traffic constitutes ~80% of records. Rare classes like Heartbleed and Infiltration have <100 samples each.
5. **Concept drift:** Models trained on this dataset are likely to perform poorly on modern traffic without retraining.
